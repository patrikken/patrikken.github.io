What is plotted
  • Each point is one configuration (a base model with one intervention setting, e.g. TabPFN + CR at one strength, or one FairTFM checkpoint). Its accuracy (or ROC-AUC) and |DP|, |EOD|, |EOP| differences are averaged over every fully finished task in the chosen group.
  • Colour = intervention type, marker = base model. The black line is the single Pareto front over all points; points on it are bold, the others faint.
  • LAFTR: the adversary matches each panel's fairness notion. Tasks still running are left out until all their units finish (the title gives the number of tasks).
What is plotted
  • Each figure fixes one base model (TabICLv2, TabPFNv2.5, or a FairTFM model used as the predictor) and shows accuracy (or ROC-AUC) against DP, EOD and EOP differences; the black line is the Pareto front over all points.
  • Base model on raw features, full training set as context.
  • + Group-Balanced: context with equally many examples per sensitive group (Fair-TabICL).
  • + Uncertain: context restricted to examples whose sensitive attribute is uncertain under conformal prediction, swept over the coverage level α (Fair-TabICL).
  • CR + base model: CorrelationRemover features, swept over its strength.
  • LAFTR + base model: LAFTR encoder features, swept over the adversarial weight γ (DP / EOD / EOP adversary on the matching panel).
  • FairTFM emb. + TabICLv2/TabPFNv2.5: FairTFM embeddings (every checkpoint) as features.
  • FairTFM: end-to-end FairTFM predictions, every checkpoint of every FairTFM model.
  • Non-ACS datasets are subsampled to 7,000 training / 3,000 test examples (stratified); ACS tasks use 10,000 examples (__ACS__).
